# NoteVault

A small browser workspace for short notes. Add and delete notes; they persist in local storage on the current browser.

## Run

Open noteVault.html in a modern browser. No build step is required.

## Privacy and limitations

Notes stay in the browser's local storage. They are **not encrypted** and should not contain secrets or sensitive information. Browser data clearing removes them. This project is a local interface prototype, not a secure vault or synchronised notes service.
